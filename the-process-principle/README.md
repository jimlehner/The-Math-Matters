# The Process Principle

This repository contains the Python code and supporting files used to reproduce select figures for the essay **The Process Principle**.

To read the full essay visit [The Math Matters](https://themathmatters.substack.com/).

![](figures/fig_xchart.png)

## About the Essay

This essay introduces readers to the process principle and its role in understanding variation, reducing costs, and improving quality.

- Defines the process principle and its role in understanding variation
- Explains why the process principle is important
- Provides a definition of variation
- Outlines the role of the process principle with regard to process behavior charts
